# Article Summarizer CLI

A local-first Python CLI that summarizes articles and text using a configurable
OpenAI-compatible endpoint (default **[Ollama]** running on `localhost:11434`).
Summaries are saved locally as Markdown files, and every run prints an
education-only disclaimer. No API keys, no accounts, no cloud required.

Built and maintained by **Asdale Dynamics, LLC** — beginner-friendly AI
education, open-source tools, and practical apps for small businesses, authors,
and healthcare workers (education only, never medical advice).

## Features

- Summarize text from an argument, one or more `--file`s, or stdin
- Configurable OpenAI-compatible endpoint (`--endpoint`) and model (`--model`)
- Defaults to a local Ollama instance (`http://localhost:11434`)
- Saves every summary locally to a `summaries/` directory (timestamped Markdown)
- Optional `--output` file and `--no-save` mode
- Custom system prompt via `--system`
- Education-only disclaimer printed with every summary
- Zero secrets, zero API keys, works fully offline once a local model is running

## Install

```bash
cd article-summarizer-cli  # or unzip/copy this folder
python3 -m pip install -e .
```

This installs the `article-summarizer` command on your PATH.

## Usage

Summarize a paragraph:

```bash
article-summarizer "Paste your article text here..."
```

Summarize from a file:

```bash
article-summarizer --file article.txt
```

Multiple files or stdin:

```bash
cat article.txt | article-summarizer
article-summarizer --file a.txt --file b.txt
```

Use a different endpoint or model (useful for any OpenAI-compatible server):

```bash
article-summarizer --endpoint http://localhost:1234/v1 --model qwen2.5 "text"
```

Save to a specific file:

```bash
article-summarizer --file article.txt --output summary.md
```

Suppress saving or the disclaimer banner:

```bash
article-summarizer --no-save "text"
article-summarizer --no-disclaimer "text"
```

Configure defaults with environment variables:

```bash
export ARTICLE_SUMMARIZER_ENDPOINT=http://localhost:11434
export ARTICLE_SUMMARIZER_MODEL=llama3
export ARTICLE_SUMMARIZER_OUTPUT_DIR=summaries
```

## Local-first by design

This tool talks only to the endpoint you configure (Ollama by default). Nothing
is uploaded, no API key is ever stored or transmitted, and summaries live on
your machine under `summaries/`.

## Education-only disclaimer

Every summary is printed between this banner:

```
EDUCATION ONLY -- This summary was generated by an AI model and is for
general educational purposes. It is not medical, legal, financial, or
professional advice. Consult a qualified professional for decisions that
affect your health, finances, or legal matters.
```

AI summaries can be inaccurate or incomplete. Always verify important
information against the original source.

## Running with Ollama

1. Install Ollama from https://ollama.com and pull a model:

   ```bash
   ollama pull llama3
   ```

2. Start the server (usually automatic after install):

   ```bash
   ollama serve
   ```

3. Run the summarizer:

   ```bash
   article-summarizer --file article.txt
   ```
